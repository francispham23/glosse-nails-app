# Gift card and ownership: API-only evidence

Each launch executes the existing scripts/runtime-financial-check.mjs through
real Password-authenticated public Convex APIs on the identified fresh backend.
See retained backend-checks.txt for the exact passed groups. The harness checks
explicit shared-card balances, rejected requests against complete financial
snapshots, ten contention rounds, self/other ownership, and update/switch/delete
effects. Internal run-guarded helpers only seed roles and read snapshots.

Read [financial policy](../../../../docs/financial-policy.md) and
[access policy](../../../../docs/access-policy.md) for relevant acceptance.
Browser transaction pilot uses Card, not gift-card redemption. No gift-card UI
selectors, scanner, native redemption or production concurrency certification
were executed by this verifier. Those acceptance criteria need their own approved
recipe and live evidence; API results alone cannot close them.
